ACADEMIC PORTFOLIO WEBSITE — MS. SHARANYA TIRUNAGARI

Preview:
1. Extract this ZIP file.
2. Keep index.html and profile-photo.jpg in the same folder.
3. Open index.html in a browser.

Before publishing:
- Replace the LinkedIn feed URL with your personal LinkedIn profile URL (the link provided was https://www.linkedin.com/feed/, not a personal profile link).
- Add B.Tech institution/year and M.Tech institution details.
- Verify employment dates and publication citations/statuses.
- Add verified certifications, awards, patents and project links.

Free publishing with GitHub Pages:
1. Create a GitHub account and a public repository named YOUR-USERNAME.github.io.
2. Upload BOTH index.html and profile-photo.jpg to the repository root.
3. Open repository Settings > Pages.
4. Select Deploy from a branch, choose main and /(root), then save.
5. Your website will appear at https://YOUR-USERNAME.github.io after deployment.
